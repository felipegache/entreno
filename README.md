# Entreno

App de entrenamiento personal. Funciona sin conexión una vez instalada y guarda los datos solo en el teléfono.

## Instalar en Android

1. Abrí **https://felipegache.github.io/entreno/** en Chrome.
2. Menú ⋮ → **Instalar app** (o "Agregar a la pantalla principal").
3. Abrila una vez con internet. Desde ahí funciona sin conexión.

Accesos directos: mantené apretado el ícono de la app.

## Actualizar

Subí los archivos nuevos al repositorio (Add file → Upload files). Al abrir la app aparece "Hay una versión nueva → Actualizar". Los datos no se tocan.

## Respaldo

Más → Exportar y respaldo. El archivo de "Exportar para revisión" es el que se sube en el chat con Claude.

## Capítulos

Los programas de entrenamiento se cargan desde Más → Capítulos. El formato está en `CAPITULOS.md`.
